# dev/ — أدوات البناء والتحقق (كيف بُنيت أدوات القراءة)

هذا المجلد يحفظ **كل ما استُخدم لبناء أدوات `tools/` والتحقق منها**، حتى لا نعيد بناءه مرة أخرى. الأدوات النهائية القابلة للتشغيل موجودة في `tools/`. ما هنا أرشيف للمرجعية وإعادة الاستخدام، وليس جزءًا من مسار التشغيل.

| المجلد / الملف | المحتوى |
|---|---|
| `workflow/diwan-plan-reading.js` | **سكربت التنسيق (Workflow)** الذي بنى الأدوات بفريق وكلاء. يمر كل جانب من الجوانب الأربعة بالمراحل الآتية: **بناء ← تحقق عدائي ← إصلاح (حتى جولتين)**. ثم **تجميع** (`read_plan.py` و`READING_GUIDE.md` وExcel)، ثم **ناقد شامل**. الجوانب الأربعة: الحوائط، والفتحات، والغرف، والهيكل مع مقارنة الأدوار. فيه سياق المشروع الكامل الذي أُعطي لكل وكيل، ونصوص مهام البناء والتحقق والإصلاح. |
| `workflow/agent_reports.json` | **تقارير الوكلاء الفعلية**: تقرير البناء لكل أداة (الاصطلاحات المكتشفة والأرقام والقيود والأسئلة)، وحكم كل مُحقق مع العيوب التي وجدها والأدلة. هنا تجد أي ملاحظة "صغرى" لم تُصلَح بعد. |
| `verify/<الموضوع>/` | السكربتات التي كتبها **المحققون** للتحقق المستقل من كل أداة مقابل كيانات DXF الخام. تفحص عينات من الحوائط والأبواب والغرف والأعمدة بالمقابض والإحداثيات، وتبحث عمّا فات الأداة. المواضيع: `walls`، `openings`، `rooms`، `structure_diff`. |
| `scratch/` | سكربتات **الاستكشاف والنماذج الأولية والترقيع** التي كتبها وكلاء البناء أثناء تعلم قراءة اللوحات. ← تفصيلها في الجدول التالي. |

### ما في `scratch/`

| النوع | الملفات | الغرض |
|---|---|---|
| جرد | `inv*.py`, `layers.py`, `blk.py`, `texts.py` | جرد الطبقات والبلوكات والنصوص |
| استكشاف | `explore*.py`, `scout*.py`, `e1*.py` | استكشاف هندسة اللوحات |
| فحوص | `dims*.py`, `tr.py`, `axes.py` | فحص الأبعاد وبلوك `tr` والمحاور |
| نماذج أولية | `proto*.py` | نماذج أولية لقارئ الغرف |
| ترقيعات | `patch*.py` | ترقيعات طُبّقت على ملفات الأدوات أثناء التطوير |
| ملخص | `key.md` | جدول الأرقام الأساسية |

> ملاحظات:
> - هذه السكربتات كُتبت لمرة واحدة. بعضها يفترض مسارات أو ملفات وسيطة لم تعد موجودة، مثل `*.pkl` و`output/...`، لذلك قد لا يعمل كما هو.
> - شغّلها من جذر المستودع مع `sys.path.insert(0, "tools")` عند الحاجة.
> - الصور والسجلات والكاش لم تُرفع؛ يُعاد إنتاجها بتشغيل الأدوات.
> - لإعادة تشغيل الـ workflow تحتاج Claude Code. يكفي تعديل نصوص المهام في السكربت ثم تشغيله.
